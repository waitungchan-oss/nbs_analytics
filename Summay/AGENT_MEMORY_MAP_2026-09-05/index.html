為什麼叫「本地 Agent」，模型卻可能在遠端？

本地部署可以指任務管理、資料、記憶和工具在你的電腦。CLI 仍可把 prompt 送到遠端模型。只有權重、推論 runtime 與呼叫路徑都在本機，才證明本地模型推論。此處沒有把 local_model 身份欄位畫成已部署的模型。

每個元件，幫你做哪一件事？

Agent 負責理解和處理工作；記憶提供以前整理的資訊；一般 Python 程式負責搬資料、限制權限與檢查結果。

catalog 存在 ≠ 提示仍可用

三個 Hub source 已過期；本次沒有 query，也沒有更新 catalog。先核對 canonical 來源，再決定是否走正式刷新。

過期 ≠ 已刪除

Offload 有刪除函式；本次沒有確認定期清理在主部署執行。主部署也沒有 Offload 目錄，不能把它當成目前的磁碟負擔。

單 run 限額 ≠ 全部歷史限額

Offload 每 run 最多 200,000 bytes。Workflow 的 25 MiB 是 soft cap；370 個 awaiting_authorization 是儲存狀態，不能直接當清理候選或 active process。
